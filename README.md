## 先分清三种"代充"，风险完全不同

市面上叫"代充"的东西，其实混着三类商品：

1. **充到你自己号上（直充）**：你保留原来的账号，聊天记录、自定义 GPT、绑定的 Codex 都在。代价是要把登录凭据交给平台。
2. **平台代注册的新号（成品号）**：拿到手是一个陌生账号，价格通常更低，但记录不归你，号主随时可能改密码或回收。
3. **共享号 / 拼车**：多人共用一个 Plus 或 Pro，额度和限速都是共享的，写代码这种连续高强度用法很容易撞上限。

搜"代充"的人，绝大多数要的是第一种。第二、三种便宜，但和"长期稳定使用"这四个字基本无关。

## Session 凭据的安全边界

"不需要密码"经常被当成安全证明，这个理解是错的。Session 或 Cookie 本身就等于账号的登录权限，拿到它的人可以像你一样访问这个账号。

实际操作里守几条底线：只在 ChatGPT 官方页面获取凭据，确认地址栏域名正确；不要把凭据、邮箱验证码、MFA 恢复码、API Key 发到群聊、评论区或截图里；一旦发现账号在陌生地点登录，先改密码再去找客服推进退款或修复。改密码可能会同时中断第三方正在处理的订阅，这个顺序要有心理准备。

**多久能到账？**
官方说法是 2 小时内。常规时段通常快得多，集中出问题的时段会拖到人工逐个处理。

**可以先买 1 个月吗？**
可以，而且建议第一次就这么做。单月的溢价最高，但试错成本也最低，跑通一次续费周期再决定要不要买多月套餐。

**该用自己的号还是买成品号？**
只要你需要保留聊天记录、自定义 GPT 或 Codex 配置，就只能直充自己的号。成品号看起来便宜，但那是一个你不掌握的账号。

可以，官网续费走的是 OpenAI 自己的支付通道，代充只是替你完成某一次或某几个月的付款，两者不冲突。
